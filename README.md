# IT Event Host - Landing Page

Профессиональная landing page для ведущего-программиста IT-мероприятий.

## Технологии

- **Nuxt 3** - Vue.js фреймворк
- **TypeScript** - Типизация
- **Tailwind CSS** - Стилизация
- **Nuxt Image** - Оптимизация изображений
- **Composition API** - Современный подход к компонентам

## Установка

```bash
# Установка зависимостей
npm install

# Запуск dev сервера
npm run dev

# Сборка для production
npm run build

# Предпросмотр production сборки
npm run preview
```

## Изображения

Проект использует изображения из Unsplash в качестве placeholder'ов. В production рекомендуется:

1. Заменить URL на собственные изображения
2. Разместить изображения локально в `public/` или `assets/`
3. Использовать CDN для оптимизации

### Рекомендуемые изображения:

- **Hero**: Портрет ведущего (вертикальный, 3:4 или 4:5)
- **About**: Ведущий на сцене, взаимодействие с аудиторией
- **Cases**: Фото мероприятий (конференции, хакатоны, митапы)
- **Testimonials**: Аватары (круглые, монохромные)

Все изображения должны быть в черно-белом или десатурированном стиле для соответствия дизайну.

## Настройка

### Контакты

Измените контактные данные в:
- `components/CTASection.vue` - email и телефон в форме
- `components/FooterSection.vue` - контакты в футере

### Контент

Все тексты находятся в компонентах и могут быть легко изменены.

### Изображения

Замените URL изображений в компонентах на собственные:
- `HeroSection.vue` - главное фото
- `AboutSection.vue` - фото на сцене
- `CasesSection.vue` - фото мероприятий
- `TestimonialsSection.vue` - аватары
