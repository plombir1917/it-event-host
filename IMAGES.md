# Руководство по изображениям

## Текущая реализация

Проект использует изображения из Unsplash в качестве placeholder'ов. Все изображения:
- Применяют grayscale фильтр (черно-белые)
- Имеют hover-эффект (переход в цвет при наведении)
- Оптимизированы через Nuxt Image (WebP, AVIF)
- Используют lazy loading (кроме Hero)

## Замена на собственные изображения

### Вариант 1: Локальные файлы

1. Создайте папку `public/images/`:
```
public/
  images/
    hero/
      portrait.jpg
    about/
      stage.jpg
    cases/
      conference-1.jpg
      hackathon-1.jpg
      corporate-1.jpg
      meetup-1.jpg
    testimonials/
      avatar-1.jpg
      avatar-2.jpg
      ...
```

2. Обновите компоненты, заменив URL на локальные пути:
```vue
<NuxtImg
  src="/images/hero/portrait.jpg"
  alt="Ведущий-программист"
  ...
/>
```

### Вариант 2: CDN / Внешний хостинг

Если используете CDN (Cloudinary, ImageKit и т.д.):

1. Обновите `nuxt.config.ts`:
```ts
image: {
  domains: ['your-cdn.com'],
  // или используйте провайдер
  providers: {
    cloudinary: {
      baseURL: 'https://res.cloudinary.com/your-cloud/image/upload'
    }
  }
}
```

2. Обновите URL в компонентах

## Требования к изображениям

### Hero Section
- **Размер**: 800x1000px (портрет) или 1200x1500px
- **Формат**: JPG (высокое качество) или WebP
- **Стиль**: Редакторский портрет, профессиональный, уверенный взгляд
- **Композиция**: Центрированное лицо или половина тела, много негативного пространства

### About Section
- **Размер**: 800x1000px (вертикальный) или 1200x800px (горизонтальный)
- **Стиль**: Ведущий на сцене, взаимодействие с аудиторией
- **Атмосфера**: Конференция, выступление, техническая презентация

### Cases Section
- **Размер**: 1200x800px (16:9)
- **Количество**: 4 изображения (по одному на кейс)
- **Стиль**: 
  - Конференция: сцена, аудитория, техническая атмосфера
  - Хакатон: команды за работой, энергия, креативность
  - Корпоративное: презентация, панель, профессиональная обстановка
  - Митап: сообщество, нетворкинг, комфортная атмосфера

### Testimonials Section
- **Размер**: 200x200px (квадрат, будет обрезан в круг)
- **Количество**: 6 аватаров
- **Стиль**: Профессиональные портреты, нейтральный фон
- **Важно**: Изображения будут в grayscale, выбирайте контрастные фото

## Обработка изображений

Все изображения автоматически:
- Конвертируются в WebP/AVIF
- Оптимизируются по качеству (85-90%)
- Применяют grayscale фильтр через CSS
- Имеют плавный переход в цвет при hover

## Рекомендации

1. **Консистентность**: Используйте единый стиль съемки для всех фото
2. **Качество**: Минимум 1200px по большей стороне
3. **Композиция**: Редакторский стиль, много воздуха, фокус на главном объекте
4. **Цвет**: Можно использовать цветные фото - они будут автоматически обесцвечены
5. **Лицензия**: Убедитесь, что у вас есть права на использование всех изображений
